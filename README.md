# Secure Authentication Lab

A small Flask-based cybersecurity project demonstrating secure user authentication controls for an authorized local environment.

## Features

- Secure password hashing
- Server-side validation
- Generic authentication errors
- Login rate limiting
- Secure session cookies
- 30-minute session lifetime
- CSRF protection
- Secure POST logout
- Parameterized SQL
- Security logging
- Automated pytest security tests

## Run Locally

```powershell
python -m pip install -r requirements.txt

python app.py
